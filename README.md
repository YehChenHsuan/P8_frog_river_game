> **適用教材**：ALICE ESL Phonics P8 (Focus Sounds: Diphthongs (ai, oi, air, oy) & Body Parts)  
> **課本學習範圍**：**Page 08 - 13**（對應各冊 student book 教學重點）

## 🌟 遊戲亮點與教育特色

1. **直覺操作降維化**：
   - 幼童可直接透過滑鼠或平板觸控點擊水面上的荷葉圖卡起跳。
   - 提供特大鍵盤方向鍵 (`A`/`W`/`D` 或 `←`/`↑`/`→`) 與底部彩色大按鈕輔助。
2. **教材圖音全面整合**：
   - 收錄 ALICE ESL Phonics P8 高解析圖卡 (`P8_flashcards_images/`) 與真人中英雙語發音 (`P8_flashcards_audios/`)。
   - 答對時即時複習強化聽力與字形連結。
3. **萌寵角色自由切換**：
   - 🐸 **小綠蛙 (Froggy)**：彈簧跳躍、水波漣漪
   - 🦆 **小黃鴨 (Ducky)**：搖擺小跳、可愛水花
   - 🐰 **小雪兔 (Bunny)**：空中轉體跳躍、星光粒子
4. **四大教育關卡模式**：
   - 🎧 **聽音跳荷葉 (Listen & Hop)**：聽音辨字，點選對應荷葉。
   - 🔤 **首字母尋寶 (Beginning Sounds)**：加強 ai, oi, air, oy 自然發音規則。
   - 🐾 **情境問答與動作 (Actions & Dialogue)**：依據課本第 Page 08 - 13 句型活動。
   - 🌟 **無盡過河 (Endless Crossing)**：無止境跳島挑戰，鍛鍊反應速度與綜合單字能力。
5. **零挫折容錯設計 (Zero-Frustration)**：
   - 答錯時荷葉僅微微搖晃並溫和提示 *"Try again!"*，小動物回到原位，絕不驟然 Game Over。
